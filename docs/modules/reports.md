# Модуль: отчёты и выгрузки

## 1. Назначение и границы
Ключевые показатели, распределение взаимодействий по этапам, выгрузки Excel/JSON и
PDF-руководства. Читает данные взаимодействий, ничего в них не меняет.
Не делает: не изменяет этапы и карточки; не является источником истины — источник в
модуле взаимодействий.

## 2. Сценарии использования
- Отчёт по этапам и продуктам за период.
- Фильтрация по роли: руководитель видит всех, КАМ — только свои взаимодействия.
- Выгрузка в Excel с корректной кириллицей; выгрузка JSON.
- Отказ: пустой период → пустой отчёт с явным нулём, а не ошибка.

## 3. Контракт
`/api/reports/*`, `/api/reports/export/*`. Колонки отчёта каноничны и общие с
фронтендом: `config/report_columns.json` (синхронизация — `scripts/sync_report_columns.py`).

## 4. Данные
Собственных таблиц нет: агрегаты считаются по взаимодействиям. Кэш агрегатов —
Redis/KeyDB (`services/report_cache.py`); при недоступности кэша считается напрямую.

## 5. Права
Область видимости отчёта зависит от роли (`tests/test_report_scope.py`): руководитель —
все, КАМ — только свои. Это проверяется тестом, а не соглашением.

## 6. Зависимости
Исходящие: БД, кэш, `openpyxl`/`python-pptx`-стек выгрузок. Входящие: `api.reports`,
страница `ReportPage`.

## 7. Конфигурация
Redis-параметры (`REDIS_URL`), лимиты выгрузок. При отключённом кэше отчёты работают
медленнее, но корректно.

## 8. Сборка и отладка
```bash
python -m pytest tests/test_report_columns.py tests/test_report_scope.py -q
python -m pytest tests/test_excel_export_cyrillic.py -q
```

## 9. Тесты
`test_report_columns.py` (канонический набор колонок), `test_report_scope.py` (роль →
видимость), `test_excel_export_cyrillic.py` (кириллица в Excel),
`test_json_export.py`, `test_pdf_layout.py`, `test_guide_pdf.py`.

## 10. Наблюдаемость
Логи кэша и выгрузок; аудит не пишется (операция чтения). Ошибки: `report_scope_denied`,
`export_failed`.

## 11. Ограничения и готовность
- Отчёты считаются по запросу: на больших объёмах нужен кэш.
- Нет конструктора произвольных отчётов.
- Готовность: область видимости покрыта тестом; кириллица не ломается в Excel.
